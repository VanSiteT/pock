Tools AI

Beranda Artikel Prompt Tools Tentang
Tools di bawah dipilih karena praktis, banyak yang bisa dipakai gratis, dan relevan untuk cuan + atur keuangan.

Chat AI Utama

ChatGPT

AI paling serbaguna. Cocok untuk buat anggaran, ide side hustle, tulis konten, dan banyak lagi.

Gratis + Berbayar Paling Populer

Google Gemini

Alternatif kuat dari Google. Bagus untuk analisis dan tugas yang butuh data terbaru.

Gratis + Berbayar

Claude

AI yang bagus untuk tulisan panjang dan penalaran. Cocok untuk buat artikel atau rencana keuangan detail.

Gratis + Berbayar

Tools untuk Konten & Side Hustle

Canva (Magic Studio)

Desain grafis + AI. Bisa buat thumbnail, konten sosmed, dan materi jual jasa dengan cepat.

Gratis + Pro

CapCut

Edit video dengan bantuan AI. Cocok untuk konten faceless di TikTok / Reels / Shorts.

Gratis

Notion AI

Catat ide, buat database klien, dan pakai AI untuk merapikan catatan kerja sampingan.

Gratis + Berbayar

Tools untuk Keuangan

Spreadsheet + AI (Google Sheets / Excel)

Masih tools paling fleksibel untuk catat pengeluaran. Bisa digabung dengan prompt AI untuk analisis.

Gratis

ChatGPT / Gemini (sebagai Asisten Keuangan)

Pakai prompt dari halaman Prompt untuk membuat anggaran, deteksi boros, dan evaluasi mingguan.

Gratis

Tools Pendukung Lain

Grammarly / LanguageTool

Merapikan tulisan bahasa Inggris atau Indonesia. Berguna kalau jual jasa menulis.

Gratis + Berbayar

Remove.bg / Photopea

Edit gambar cepat. Berguna untuk keperluan konten atau jasa desain sederhana.
